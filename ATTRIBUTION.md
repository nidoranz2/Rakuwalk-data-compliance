## OpenStreetMap attribution

**© OpenStreetMap contributors**

RakuWalk uses an OSM-derived routing database under ODbL 1.0. See [`ODBL-COMPLIANCE.md`](ODBL-COMPLIANCE.md).

## Project PLATEAU attribution

**Project PLATEAU / MLIT**

RakuWalk converts PLATEAU building geometry and derives modelled building shade. The resulting shade values are estimates generated by RakuWalk, not measured street-level shade or temperature.

## Processing disclosure

For source datasets that RakuWalk converts, filters, interpolates, contracts, or otherwise transforms, RakuWalk discloses that the data has been processed by the project rather than presenting the result as an unchanged publication of the provider.
